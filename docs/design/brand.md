## 2. 标准产品名称

产品所有用户可见位置统一使用：

> FF - LLM Wiki知识库

使用规则：

- `FF` 和 `LLM Wiki` 保持当前英文大小写。
- 半角连字符 `-` 两侧各保留一个空格。
- `Wiki` 与“知识库”之间不增加空格。
- 不把用户可见产品名缩写为 `LMVK`、`LlmWikiKnowledge` 或其他临时名称。
- `LlmWikiKnowledge` 仅作为仓库目录、历史文档路径和必要的内部工程标识保留。
- 展开侧边栏、浏览器标题、启动状态、关于信息和其他出现产品名称的界面均使用完整标准名称。
- 侧边栏收起时可以只显示标志；任何文字形式仍须使用完整标准名称。

## 3. 标志资产

| 项目 | 约束 |

| 品牌源文件 | `docs/assets/brand/ff-llm-wiki-logo.png` |

标志使用规则：

- 品牌源文件保持原样，不覆盖、不重绘、不反色、不重新配色。
- 保持 1:1 比例，不拉伸、挤压、裁掉图形节点或改变黑色方形画布。
- 浅色和深色主题均使用同一源标志。浅色主题可由外层容器提供留白；深色主题可由外层容器提供克制边界，不能修改位图本身。
- 应用实现可以从品牌源文件生成不同尺寸的发布副本，但必须保留原始构图、颜色和比例；源文件继续作为视觉对照基线。
- 标志与产品名称组合时，标志位于名称左侧，二者不重叠，名称保持完整可读。
- 不为标志增加发光、渐变、旋转、持续呼吸或与产品任务无关的装饰动画。

界面头像例外：侧边栏顶部与浏览器标签页图标使用 `frontend/public/knowledge-avatar-minimal.png`（蓝底白色书形，SHA-256：`5ee95dfcfae1d50ec89246c177bd78d7ea24c22c8d4338baf4180ca7e9165e88`），侧边栏无障碍文本为 `FF - LLM Wiki知识库 头像`。展开、收起及明暗主题均使用同一张图片；不替换上表中的正式品牌源文件，也不影响其他位置使用正式标志。

## 4. 署名与脚标

凡界面、启动页、关于信息、导出内容或产品画面需要出现脚标、版权或研发署名时，统一使用：

> @2026 赋范空间 独家自研

使用规则：

- 保持 `@2026`、空格和中文文字完全一致，不擅自替换为 `© 2026`、英文翻译或其他宣传语。
- 该文字是署名信息，不默认作为链接或按钮。
- 不强制在每个业务页面增加常驻页脚；一旦出现同类署名，必须使用唯一标准文案。
- 署名为辅助层级，不能遮挡知识、来源、引用、编译状态或图谱控件。

## 5. 主要界面应用

| 位置 | 使用方式 |
|---|---|
| 展开侧边栏 | 蓝底书形头像 + 完整产品名 `FF - LLM Wiki知识库` |
| 收起侧边栏 | 只显示蓝底书形头像，并提供对应无障碍文本 |
| 浏览器标签页图标 | 蓝底书形头像 |
| 浏览器标题 | `FF - LLM Wiki知识库`，具体页面名可置于其后 |
| 首次加载与错误恢复 | 使用标志和完整产品名，不使用内部仓库名 |
| 关于信息或产品脚标 | 使用 `@2026 赋范空间 独家自研` |
| README 与产品文档 | 使用完整产品名，并说明仓库内部名称仅为 `LlmWikiKnowledge` |

## 6. 验收门槛

- 用户界面中不存在 `LMVK`、`LlmWikiKnowledge` 等旧产品名。
- 抽查产品名称的空格、连字符、英文大小写和中文组合与本规范一致。
- 正式品牌源文件与本规范 SHA-256 一致；发布尺寸副本与源文件视觉构图一致。侧边栏头像和浏览器标签页图标均与上文记录的 SHA-256 一致。
- 标志及侧边栏头像在明暗主题下不变形、不被裁切、不过曝、不与背景融为不可辨识状态。
- 出现脚标或研发署名时，文案逐字等于 `@2026 赋范空间 独家自研`。
