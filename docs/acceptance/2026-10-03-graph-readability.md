# FF - LLM Wiki知识库：图谱可读性验收

日期：2026-10-03

对应 `F-03`、`AC-F03-01`、`AC-F03-02` 和 Spec §7.4。技术实现补充见
`docs/architecture/0001-lmvk-mvp-technical-plan.md` §4.2.1。
本轮只改前端图谱展示，不修改来源、知识、证据、关系、编译或后端接口。

## 改动与观察

| 改动 | 可观察结果 |
|---|---|
| 投影名称与避让 | 全景优先显示枢纽；无枢纽时按真实度数选取少量名称。选中名称优先，不与其他标签、搜索、图例或详情重叠。空间不足时减少标签，不缩小文字或补造节点。 |
| 稳定的选中邻域 | 点击真实名称后聚焦该节点及直接邻接，持续显示选中名称，路过其他节点的悬停不替换当前聚焦；有向的聚焦边显示箭头，无关对象降低存在感。 |
| 空间与相机 | 有限电荷作用范围减少孤立节点散布；根据真实邻域及当前观看方向调整相机。桌面详情和手机底部详情不挤占标签可用区域。 |
| 双主题光效 | 收敛深色 bloom，显式设置场景背景并增加输出转换，实际画布底色恢复到主题值。浅色绿色由 `#65a30d` 调整为 `#629f0d`，节点、标签和图例同步，后端领域颜色不变。 |
| 运动与联动 | 自动旋转默认关闭，手动开启后标签随实际相机运动；关系流动、领域筛选、搜索、减少动态效果及进入真实知识页面均可用。 |

保留 `3d-force-graph`、Three.js 和原有 `GraphProjection` 身份、方向及关系语义；
没有增加图库数据、渲染库或后端依赖。没有把稀疏图谱中的孤立知识强行连线。
