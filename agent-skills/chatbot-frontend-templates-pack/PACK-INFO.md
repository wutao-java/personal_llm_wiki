# 对话产品模板 · 八形态基线画廊（v1.0.0）

## 这个包是什么

你在做 AI 对话产品前端（Chatbot / RAG 溯源 / Agent 链路 / 生成式 UI / 画布 / 深研 / 分支 /
多智能体）时，装上它，你的 Agent 就先问一句"这个产品的信任来自哪"，从八种实测过的产品级布局里
选定基线，搬共享层契约起步，改差异区与 mock 即得像真产品的对话骨架——接你自己的后端只改一个钩子。
一句首要纪律：**基线模板 ≠ 演示馆**，要克制中性像 ChatGPT / Perplexity，不是渐变霓虹展览馆。

## 装上后，你的 Agent 能做什么

- **选得对**：按"信任来自哪"一句判句选模板（出处可查→02 / 过程透明→03 / 少打字多点选→04 /
  产出物是文档→05 / 长任务→06 / 方案对比→07 / 分工协作→08 / 都不特殊→01）；你点名时弹画廊让你亲挑。
- **把事做对**：搬 shared.css token + 骨架类名 + shared.js（window.CT）起步，每页只写差异区与 mock，
  单页 200 行级；从零一整套时按"三决策→index 先行→逐页建"防方向性返工；接真后端只改
  CT.demoReply / CT.stream 两个钩子。
- **不做错事**：守住红线——不做炫酷展览馆、禁含糊词与裸 hex、不留死按钮、craft 底线五条。
- **知道做没做好**：干完自动跑 Playwright 明暗双主题闭环——零 console error + 交互真响应 +
  双主题都过，长模拟（03/06/08 跑 8~16 秒）等跑完再截图。
- **出问题能查**：弯引号截断 / 流式撕裂标签 / 泳道错位 / 主题按钮误判等 8 条实测坑按症状定位，
  表外症状按通用排查降级不硬套。

## 八种布局形态（画廊即选即用）

| # | 形态 | 对标 | 差异区 |
|---|---|---|---|
| 01 | 基线对话 | ChatGPT | 无（基线三段式） |
| 02 | RAG 溯源 | Perplexity | 右侧来源面板 · 引用角标定位原文高亮 |
| 03 | Agent 工作台 | Manus | 右侧执行链路 · 步骤卡 pending→running→done |
| 04 | 生成式 UI | 回答即组件 | 消息内 widget · tab/单选/提交回传 |
| 05 | 画布协作 | Artifacts / Canvas | 右半屏画布 · 版本切换 · 圈选只改这里 |
| 06 | 深度研究 | 长任务 | 消息内进度卡 · 五阶段 · 信源入库 |
| 07 | 分支对话 | 非线性树 | 顶部对话树 · 切路径 · 并排对比采用某支 |
| 08 | 多智能体 | 团队编排 | 右侧团队面板 · 每 agent 一色一角色 · 交接线 |

## 怎么用

1. **安装**：把本包目录放入 `.claude/skills/`（Claude Code）或 `agent-skills/`（Codex）。
2. **召唤**：本包只在你点名时激活（对话产品前端 / Chatbot 界面 / RAG 溯源界面 / Agent 链路界面 /
   对话产品模板）——
   - "我要做带溯源引用的 RAG 产品前端，该用哪个模板？"
   - "帮我起一个 Agent 工作台的对话前端骨架，接我自己的后端"
   - "用对话产品模板选型，弹画廊让我挑一个"

## 30 秒见效

复制这句话给你的 Agent：

> 我要做带溯源引用的 RAG 产品前端，该用哪个模板？

装包前它会随手套个渐变炫酷或基线布局、不问"信任来自哪"、裸 hex 散落、按钮无反馈；
装包后它会答"信任来自出处可查→02 RAG 溯源"并给出搬共享层起步三步 + 只改 CT.demoReply 接后端。
详见 [quick-run.md](quick-run.md)。
