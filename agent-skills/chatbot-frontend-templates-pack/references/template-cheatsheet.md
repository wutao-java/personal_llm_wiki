## 选型判句回顾

"这个产品的信任来自哪"：出处可查→02 / 过程透明→03 / 少打字多点选→04 / 产出物是文档→05 /
长任务→06 / 方案对比→07 / 分工协作→08 / 都不特殊→01 基线。八模板共用同一模拟场景
（"帮我调研 2026 年 AI 客服技术方案"），换场景只换各页 mock 文案。

## 01 · 01-baseline.html — 基线对话（ChatGPT 式）

- **差异区**：无（就是基线三段式：侧栏会话 + 消息流 + 输入框）。
- **关键交互**：思维链 `details.think` 折叠；入场流式打字（CT.stream）；消息 hover 操作栏；
  新建对话 → 空态 + 建议芯片（点了真发送）。

## 02 · 02-rag-citations.html — RAG 溯源（Perplexity 式）

- **差异区**：右侧来源面板（`.side-panel`）。
- **关键交互**：引用角标 `.cite` 点击 → 面板定位来源卡、展开命中段落 `<mark>` 高亮；
  置信度分级 pill；"查不到就说查不到"兜底条；未采用来源折叠区。

## 03 · 03-agent-trace.html — Agent 工作台（Manus 式）

- **差异区**：右侧执行链路。
- **关键交互**：步骤卡 pending→running（转圈）→done，含失败→重试演示；每步可展开 INPUT/OUTPUT/
  耗时；顶部统计（总耗时/工具调用/重试）实时累加。**长模拟 8~16 秒，验收等跑完再截图。**

## 04 · 04-genui.html — 生成式 UI（回答即组件）

- **差异区**：消息流内嵌 `.widget`。
- **关键交互**：tab 切换（表格/图表）；单选方案卡；提交按钮 → 选择回传 → 流式追加对应 AI 消息
  （闭环演示）。

## 05 · 05-canvas.html — 画布协作（Artifacts / Canvas 式）

- **差异区**：整个右半屏画布。**布局特殊：无会话侧栏，左窄对话列。**
- **关键交互**：v1/v2/v3 版本切换；diff-block "本轮修改"高亮；圈选文字浮出"只改这里"按钮
  （selection API + fixed 定位）。

## 06 · 06-research.html — 深度研究（长任务）

- **差异区**：消息内进度卡。
- **关键交互**：五阶段 checklist + 进度条 + 信源逐个入库（favicon 弹入）+ 实时日志行；
  跑完流式交付报告卡（目录/引用角标/导出按钮）；可暂停。**长模拟 8~16 秒。**

## 07 · 07-branching.html — 分支对话（非线性树）

- **差异区**：顶部 SVG 对话树导航。
- **关键交互**：节点点击切路径（消息流重渲染）；"对比分支" → 两栏并排 + "采用这支"；
  数据结构：消息存 parent 指针，当前对话 = 根到所选节点的路径。

## 08 · 08-multi-agent.html — 多智能体（团队编排）

- **差异区**：右侧团队面板 + 消息署名。
- **关键交互**：每个 agent 一色一角色 pill；交接分隔线 `.handoff`；编排剧本顺序演出
  （并行→交接→验收）；泳道 timeline 小图。**长模拟 8~16 秒；泳道序号用类名别用 nth-child。**
