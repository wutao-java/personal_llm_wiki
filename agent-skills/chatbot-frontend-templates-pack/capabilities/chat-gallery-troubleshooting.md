# 8 坑排查表 · 对话模板渲染/交互故障

## 何时使用

对话模板出现渲染或交互异常（中文被截断 / 流式撕裂标签 / 泳道序号错位 / 主题按钮显示反了 /
透明色不对）时按症状定位。症状明显在对话模板之外（后端 500、接口报错）→ 让渡对应技能。
表外症状按通用排查降级，不硬套。

## 8 坑对照（症状 → 根因 → 修法）

| # | 症状 | 根因 | 修法 |
|---|---|---|---|
| 1 | 泳道 / 步骤序号错位 | 兄弟元素里混了分隔线，`.lane:nth-child(2)` 数到分隔线头上（泳道+handoff 交错，真实序号 1/3/5） | 用**类名**或真实序号定位，别用 nth-child 想当然 |
| 2 | placeholder 等属性里中文被截断 | HTML 属性值里写了**直引号** `"`，把属性提前闭合 | 属性值里中文引号必须用**弯引号** `“”`（U+201C/201D） |
| 3 | 主题按钮"显示反了"像 bug | 按钮显示的是"将切换到"的**目标态**；用 JS 直接改 `dataset.theme` 会绕过 label 更新 | 不是 bug，用 CT 的主题切换走正常 label 更新，肉眼验证时别误判 |
| 4 | 透明色在明暗主题下不对 | `rgba` 硬编码在两套主题下失配 | 用 `color-mix(in srgb, var(--a) 55%, transparent)`——明暗通用、好维护 |
| 5 | 流式打字把 HTML 标签撕裂 | 用 `innerHTML` 逐字符截断，切在标签中间 | **深拷贝 DOM 树、按文本预算裁剪节点**（见 assets/shared.js 里 CT.stream 的 clip） |
| 6 | 有"点了没反应"的按钮 | 按钮没绑任何反馈 | 按钮地板：统一绑 toast 说明"此处接真实逻辑"，需要静默的标 `data-silent` |
| 7 | Playwright 截图显示"没渲染" | 长模拟（03/06/08 跑 8~16 秒）**截了半程** | `wait_for` 给足时间，**等跑完再截图** |
| 8 | 双击打开主题偏好丢失/与验证不一致 | `localStorage['ct-theme']` 在 `file://` 与 `http://localhost` 是不同 origin，不互通 | 双击打开用 file:// 即可；**验证一律用 http** 起本地服务 |

## 表外症状怎么办（不在上表内时）

不把"最像的一条"硬套上去（那是误诊）。如实声明"此症状不在本包收录的 8 坑内"，按通用排查降级：
F12 看具体渲染 / 确认 `<meta charset>` 与字体加载链 / 查 z-index 层叠上下文 / 二分定位。
给下一步取证动作，不编造表内根因。

## 反模式

- ❌ 用 `nth-child` 想当然数序号——被分隔线挤错位，用类名或真实序号。
- ❌ 见"中文被截断"就乱改字体 / 编码——先查属性值里是不是写了直引号（坑 2）。
- ❌ 把表外症状（如 z-index 层叠冲突）硬套成表内最像的一条根因——误诊比不诊断更伤信任。
