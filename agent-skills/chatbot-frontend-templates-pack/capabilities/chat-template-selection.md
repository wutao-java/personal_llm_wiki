# 八形态选型 · "这个产品的信任来自哪"

## 何时使用

要做一个对话产品前端、但还没定用哪种布局形态时——先用一句判句选定八模板之一作基线。
已经知道用哪个模板、要开始搭骨架 → 走 chat-shared-layer-contract；要从零把一整套八页做出来
→ 走 chat-build-workflow。本能力只解决"选哪个形态"。

## 核心思路

**同一个提问，八种回答方式**：八个模板共用一个模拟场景（"帮我调研 2026 年 AI 客服技术方案"），
差别只在"这个产品靠什么让用户信任它的回答"。选型只问一句——**这个产品的信任来自哪**：

| 信任来自… | 选 | 形态 | 差异区 |
|---|---|---|---|
| 出处可查（答案要能溯源到原文） | **02** RAG 溯源（Perplexity 式） | 右侧来源面板 · 引用角标定位原文高亮 |
| 过程透明（看得到它怎么一步步做的） | **03** Agent 工作台（Manus 式） | 右侧执行链路 · 步骤卡 pending→running→done |
| 少打字多点选（回答长成可交互组件） | **04** 生成式 UI | 消息流内嵌 widget · tab/单选/提交回传 |
| 产出物是文档（边聊边改一份作品） | **05** 画布协作（Artifacts/Canvas 式） | 右半屏画布 · 版本切换 · 圈选只改这里 |
| 长任务（分钟级要看进度） | **06** 深度研究 | 消息内进度卡 · 五阶段 checklist · 信源入库 |
| 方案对比（要并排看几条分支） | **07** 分支对话 | 顶部对话树 · 切路径 · 两栏并排采用某支 |
| 分工协作（一支队伍在办事） | **08** 多智能体 | 右侧团队面板 · 每 agent 一色一角色 · 交接线 |
| 都不特殊（就是标准问答） | **01** 基线对话（ChatGPT 式） | 无差异区，就是基线三段式 |

## 核心流程

1. 听清用户产品的**核心信任诉求**，套上表判句给出**一个**默认模板（不并列多个）。
2. **用户显式点名"用对话产品模板选型 / 弹画廊让我挑"** → 起本地服务打开 `assets/index.html`
   选型画廊，把八张卡片（精确布局线框 + accent 虚线标差异区）一览给用户，**请用户亲自点名**，
   不替用户定形态。
3. 给出选定模板后，交棒 chat-shared-layer-contract 搬骨架（或 chat-build-workflow 走全流程）。

## 反模式

- ❌ 不问"信任来自哪"就随手套一个布局——多半套成基线或炫酷展览馆，白做。
- ❌ 用户显式点名选型却不弹画廊、直接替用户挑一个——审美与形态的决定权在用户。
- ❌ 一次并列推荐三四个模板让用户自己纠结——给一个默认 + 一句"若你更看重 X 则改用 Y"。
