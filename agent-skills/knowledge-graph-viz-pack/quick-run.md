# Quick Run · 30 秒见效

## 演示任务

复制给你的 Agent：

```
打开知识图谱星图馆画廊，让我看看十种可视化范式
```

## 你应该看到

- Agent 在本包 assets 目录起本地服务（`python3 -m http.server`），打开 assets/index.html 星图馆画廊。
- 它把十种范式（GPU 星云 / 辉光深空 3D / 语义地形 / 光纤束 / 星阵矩阵 / 结构之弦 / 时间演化 / 双曲空间 / 语义山脉 / 关系之环）一览呈现，并说明各自适用的数据规模与场景。
- 它请你**亲自点名**要接入的范式，而不是替你挑一个——审美的决定权在你。

## 对照（没装包时的典型表现）

不装包时，Agent 直接手写一个 force 布局 SVG：圆圈连线、目测配色、无种子随机刷新即变布局，也不会问"你想回答什么问题"。你拿到的是一张千篇一律的默认图，而不是十种实测范式里你亲选的那一种。

## 没生效？

1. 确认包目录在 `.claude/skills/` 或 `agent-skills/` 下且含 SKILL.md。
2. Codex 用户可显式调用：`$knowledge-graph-viz-pack`。
3. 仍有问题 → 课程平台「FuFan Agent 控制台」提交反馈。
