# 知识图谱可视化 · 星图馆（v1.0.0）

## 这个包是什么

你在做知识图谱前端时，装上它，你的 Agent 就把"默认圆圈连线图"升级成十种实测通过的深空天文台级可视化——先弹画廊让你亲选范式，再把你项目的真实图谱数据适配进模板，最后跑截图验证到零 error。

## 装上后，你的 Agent 能做什么

- **选得对**：面对你的数据，按"想回答什么问题→五大家族→范式"决策链选可视化，默认弹十范式画廊让你亲选，不替你定审美。
- **把事做对**：识别上游图谱产物（GraphRAG JSON / GBrain wiki 互链 / 通用边表）映射进 data.js 契约，套展厅模板产出可视化——同一份数据换任意投影只改一个 data.js。
- **不做错事**：改配色先过机检（亮度带/色度/CVD/对比四项），引库锁 CDN 源，bloom 从安全起点起调——霓虹目测色一律拦。
- **出问题能查**：白屏/过曝/发虚/隐形/动画失效，按 8 条实测坑的症状→根因→修法表定位，表外症状按通用排查降级。
- **知道做没做好**：干完自动跑 Playwright 截图闭环——零 console error + 视觉达标 + 交互点验，三条不过不算交付。

## 十种可视化范式（画廊即选即用）

| # | 范式 | 技术 | 适用 |
|---|---|---|---|
| 01 | GPU 星云 | cosmos.gl / WebGL | 万级~百万级节点 |
| 02 | 辉光深空 3D | three.js / Bloom | 数百节点、叙事炫感 |
| 03 | 语义地形图 | d3-contour / canvas | 嵌入/降维分布 |
| 04 | 光纤束 | d3 层次边捆绑 | 有层级、看汇流 |
| 05 | 星阵矩阵 | canvas 邻接矩阵 | 稠密图首选 |
| 06 | 结构之弦 | d3 SVG Hive⇄Arc | 确定性可复现 |
| 07 | 时间演化 | canvas + 时间轴 | 叙事性最强 |
| 08 | 双曲空间 | 庞加莱圆盘 / Möbius | focus+context |
| 09 | 语义山脉 3D | three.js 地形 | 密度地貌漫游 |
| 10 | 关系之环 | d3.chord | 宏观聚合视角 |

## 怎么用

1. **安装**：把本包目录放入 `.claude/skills/`（Claude Code）或 `agent-skills/`（Codex）。
2. **召唤**：本包只在你点名时激活（关键词：可视化 / 美化 / 优化 / 酷炫 / 星图馆）——
   - "用星图馆优化这个知识图谱，太丑了"
   - "把图谱换成酷炫的 3D 星云可视化"
   - "哪种图谱可视化范式适合我的数据，弹画廊让我选"

## 30 秒见效

复制这句话给你的 Agent：

> 打开知识图谱星图馆画廊，让我看看十种可视化范式

装包前它会直接手写一个圆圈连线的 force 图（目测配色、刷新即变布局）；装包后它会起本地服务打开十范式画廊、请你亲选范式。详见 [quick-run.md](quick-run.md)。
