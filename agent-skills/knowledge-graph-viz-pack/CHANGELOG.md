## v1.0.0 (2026-07-14) 首发：6 项能力

十种实测可视化范式 + data.js 数据契约 + 深空天文台视觉系统 + 随包配色校验器，首发六项能力：

### 新增能力
- 十范式选型（决策）：按"想回答什么问题→五大家族→范式"决策链，默认弹画廊让用户亲选，不替用户定审美。
- 上游图谱产物→data.js 适配（方法）：GraphRAG 自建 JSON / MS GraphRAG parquet / GBrain wiki 互链 / 通用边表四类映射配方；OCR 版面产物明确不适配。
- data.js 数据契约 + 套模板（方法）：同一份数据多种投影，接入只改 data.js；mulberry32 种子随机、degree 预计算、DOMAINS ≤8。
- 视觉红线（约束）：配色必过 validate_palette 机检、cosmos.gl 只用 esm.sh、bloom 从 1.3/0.6/0.15 起、three 主包+examples 同锁 @0.170.0。
- 渲染故障排查（诊断）：8 条实测坑 + Hive/双曲两条几何坑的症状→根因→修法表，含表外症状通用降级。
- 截图验证闭环（验收）：Playwright navigate→等收敛→截图→查 console→改→重来，零 error + 视觉达标 + 交互点验三条硬标准。

### 工具脚本
- scripts/validate_palette.js：零依赖 node 分类调色板四项机检（亮度带 / 色度下限 / 相邻色 CVD 分离 / 底色对比），内置 `--selftest` 绿例全过 + 红例超亮度带双向自证。

### 随包资产
- assets/：十展厅 HTML + index.html 画廊 + data.js 契约范例 + shared.css 深空视觉系统，共 13 个可改模板。
