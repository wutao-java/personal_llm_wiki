# Quick Run · 30 秒见效

## 演示任务

复制给你的 Agent：

```
我有一个编译式 RAG 项目：raw/ 里放了三篇资料，wiki/ 是编译产物。请把 raw/ 三篇编译成互链 wiki；然后我把其中一篇源文档的一个结论改掉、但先不重新编译，你直接对这个结论发起查询会返回什么？请说明为什么，并演示如何用 git 证明 raw/ 没被你改动。
```

## 你应该看到

- 明确声明源层 `raw/` 只读、编译产物落在 `wiki/`，查询只读 wiki 命中产物（不重新通读 raw）。
- 指出"改了源不重编译 → 查询仍答旧编译产物（答旧值）"，编译式 RAG 不会自动同步；重编译后才返回新值。
- 用 `git diff --stat -- raw/` 无输出自证源不可变，并建议跑 `scripts/verify_source_immutability.py` 做完成后自检。

## 对照（没装包时的典型表现）

不装包时，Agent 往往把三篇原文直接塞进上下文临时归纳（解释执行）；你改了源它照答旧值、也不会提示"需要重编译"，更不会验证 raw/ 是否被污染——错得很安静。

## 没生效？

1. 确认包目录在 `.claude/skills/` 或 `.agents/skills/` 下且含 SKILL.md。
2. Codex 用户可显式调用：`$compiled-rag-pack`。
3. 仍有问题 → 课程平台「FuFan Agent 控制台」提交反馈。
