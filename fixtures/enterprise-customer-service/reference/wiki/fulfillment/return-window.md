# 退货时限

## 摘要

更新版本符合条件的商品可在签收后十五个自然日内申请无理由退货；法定和业务例外仍按清单处理。

## 核心说明

本页由多个来源中的定义、处理规则和可核验关系重组而成。它以 K-FULFILLMENT-RETURN-WINDOW 作为稳定身份，标题微调或图谱重新布局不会改变该身份。当前内容属于知识版本 KS-RETAIL-SERVICE-1.1。
